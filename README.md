# 魔塔 · 五界

一款浏览器里直接玩的魔塔：五个世界、每界 50 层 + 首领殿 + 隐藏支线，一个勇士从魔塔一路打到深海。单个 `index.html`，无需安装、无需登录，手机横竖屏都能玩。

**怎么玩**：打开 `index.html`（或 GitHub Pages 链接）即可。点击地图任意格子会自动寻路走过去；点到怪物会先弹出属性卡，确认后才开打。

---

## 一、核心规则

| 项目 | 说明 |
|---|---|
| 战斗 | 回合制，勇士先手。每回合伤害 = 攻击 − 对方防御。**防御 ≥ 怪物攻击时，它伤不到你**；攻击 ≤ 怪物防御时打不动 |
| 预览 | 怪物手册 / 点击怪物会显示「预计损失生命」（含暴击闪避吸血的期望）和「最坏情况」 |
| 钥匙与门 | 黄 / 蓝 / 红钥匙开对应颜色的门，走上去自动消耗；钥匙不跨颜色通用 |
| 清场门 | 杀光本层所有怪物才会打开 |
| 楼层传送 | 长老赠送的传送卷轴可回到任何去过的楼层（顶部标签可切换世界） |
| 存档 | 5 个手动存档位 + 自动存档；打开页面自动读取最新存档 |
| 难度 | 普通 ×1.0；困难：怪物生命 ×1.15；地狱：怪物生命 ×1.4、攻击 ×1.05、药水 ×0.9。难度倍率在前 20 层逐步生效 |

### 数值速查（魔塔，其他界见「境界」一节）

| 道具 | 效果 |
|---|---|
| 红宝石 / 蓝宝石 | 攻击 / 防御 +3（1–10层）、+5、+7、+9、+11（41–50层）。只出现在单数层 |
| 红药水 / 蓝药水 | 生命 +200 / +500（固定值，不随楼层变化） |
| 圣水 | 放入背包随时用，回复**当前**生命的 30%——血越多用越划算。每界第 9、19、29、39、49 层各一瓶 |
| 升级 | 每级生命 +60~350、攻防 +1~5。等级只是点缀，成长主要靠宝石、装备和商店 |

## 二、装备系统

五个部位：**剑**（攻击）、**盾**（防御）、**鞋**（闪避）、**帽**（暴击，暴击伤害 ×2）、**戒指**（吸血）。

**固定掉落**（每界相同楼层）

| 楼层 | 装备 |
|---|---|
| 3 / 4 | 铁剑 / 铁盾 |
| 13 / 14 | 钢剑 / 钢盾 |
| 23 / 24 | 银剑 / 银盾 |
| 33 / 34 | 秘银剑 / 秘银盾 |
| 43 / 44 | 龙骨剑 / 龙骨盾 |
| 6 / 7 / 8 | 白色 帽 / 鞋 / 戒指 |
| 26 / 27 / 28 | 蓝色 帽 / 鞋 / 戒指 |
| 46 / 47 / 48 | 金色 帽 / 鞋 / 戒指 |

**颜色决定初始属性**（Lv1，魔塔数值；其他界剑盾 ×5ᵏ，百分比不变）：

| 颜色 | 剑 攻击 / 盾 防御 | 鞋 闪避 | 帽 暴击 | 戒指 吸血 |
|---|---|---|---|---|
| 白 | 10 | 3% | 4% | 3% |
| 绿 | 25 | 3.9% | 5.2% | 3.9% |
| 蓝 | 45 | 4.9% | 6.6% | 4.9% |
| 紫 | 70 | 6.3% | 8.4% | 6.3% |
| 金 | 100 | 8.1% | 10.8% | 8.1% |

固定剑盾的材质与颜色一一对应：铁 = 白、钢 = 绿、银 = 蓝、秘银 = 紫、龙骨 = 金。同一部位，颜色越高一定越强。

**随机掉落**：普通怪按星级 3%~11%（设置里可调稀少 / 标准 / 丰富），Boss 与守关精英**必掉**。随机装备最多比当前楼层段的固定装备高一档：1–12 层最高绿，13–22 层最高蓝，23–32 层最高紫，33 层起可出金；Boss / 精英至少掉本段颜色，30% 高一档。

**强化**：只消耗精华，Lv1→2 需 1 颗，Lv9→10 需 9 颗；每级 +25% 基础值（Lv10 = 3.25 倍）。
**熔炼**：返还 品质² + 已投入精华的 80%。
**精华来源**：熔炼、精华袋（+20）、商店、试炼之间。多余精华可在背包里兑换金币。

## 三、商店与 NPC

| 星级 | 名称 | 出现层（魔塔） | 出售 |
|---|---|---|---|
| ★ | 杂货铺 | 5 | 生命 / 攻击 / 防御 |
| ★★ | 武器铺 | 15 | 攻防 / 黄钥匙 ×2 |
| ★★★ | 炼金坊 | 25 | 攻防 / 精华 |
| ★★★★ | 秘宝阁 | 35 | 攻防 / 精华 / 本段颜色装备（30% 高一档） |
| ★★★★★ | 龙匠殿 | 45 | 攻防 / 精华 / 本段颜色装备（30% 高一档） / 直接升一级 |

- 商店每次购买涨价 15%，买满 20 次后**封顶**（最高为基价 ×4），之后不再涨价，也**不会售罄**。每次加攻防 = 当层宝石值的 2 倍。
- 只有站在商店门口（底边正中）才能交易。
- **老人**（第 2、7、12…47 层，每 5 层一位）：出售黄 / 蓝 / 红钥匙，价格随楼层上涨。
- **贤者**（被囚的老人，第 3、11、17、27、37、47、50 层）：给出本界的关键提示，比如裂纹墙的位置。
- **长老**（序章）：讲述剧情，赠送怪物手册、传送卷轴、2 把黄钥匙、1000 生命、50 金。

## 五、隐藏支线

在首领层（或附近）的裂纹墙后面找到**暗梯**，可以进入地图上没有的隐藏楼层。隐藏层怪物更密，奖励以宝箱、精华袋、黄金宝匣（必出比本段高一档颜色的装备，最高金色）为主。传送卷轴里会标注为「X层支线·隐藏N」。

| 世界 | 支线入口 → 层数 → 尽头 |
|---|---|
| 魔塔 | 10 → 1 层；20 → 2 层；30 → 2 层 → **试炼之间**；40 → 3 层 → **宝库** |
| 仙界 | 10 → 2 层；20 → 1 层；30 → 3 层 → **宝库**；40 → 2 层 → **试炼之间** |
| 地下 | 8 → 2 层；18 → 3 层 → **试炼之间**；28 → 2 层；38 → 3 层 → **宝库** |
| 陆地 | 10 → 1 层；25 → 3 层 → **试炼之间**；40 → 2 层 → **宝库** |
| 水中 | 10 → 2 层；20 → 3 层 → **试炼之间**；30 → 1 层；40 → 3 层 → **宝库** |

**宝库**：由宝库守护兽把守，里面是宝箱、黄金宝匣、精华袋、宝石和圣水。

**试炼之间**：站在召唤阵上 3 秒召唤一波 8 只怪（首领 + 死灵 + 巨像）。每清一波再站上去，下一波更强（×1.15），回报涨得慢（×1.08）；每 5 波出一袋精华。这里没有药水，吸血减半——适合刷金币、经验和精华，量力而行。

## 六、五界一览

一个勇士贯穿五界。通关一界后解锁下一界，可以随时用传送卷轴在已解锁的世界之间往返。

### 境界压制与境界恢复

- **首次进入更高一界**：属性被收束到该界起点（攻防 10×5ᵏ、生命 1000×5ᵏ），上一界打得越好起点越高（0.7~1.5 倍）。旧界的剑盾按 1/5 折算，饰品百分比不变，精华、钥匙、背包保留，金币最多带 300。
- **每一界的身体单独记忆**：攻防、生命、等级、经验、金币按世界分别保存。回到低一界时恢复你在那里的全部实力，可以继续清理之前的怪；再上去时恢复高界的身体。
- 每一界的数值是上一界的 5 倍（宝石、药水、怪物同比放大），所以数字不会爆炸。

### 1. 魔塔 · 目标：公主

基准世界，没有特殊规则。商店在 5/15/25/35/45 层，精英在 8/18/28/38/48 层。

### 2. 仙界 · 目标：仙尊

- **规则**：商铺不卖生命，血只能靠药水、圣水与吸血——戒指在这一界最值钱。
- **云梯**：第 6↔8、16↔18、26↔28、36↔38、46↔48 层各有一对云梯，踏上直通两层之上或之下。
- 商店 4/14/24/34/44，精英 7/17/27/37/47，清场门 15/35，祭坛 22/42。
- 首领：南天门守将、赤霄将军、紫府仙官、北斗星君、天魔祖师。

### 3. 地下 · 目标：封印之匣

- **规则**：传送卷轴只能站在楼梯口使用。
- **岩浆**：第 5、7、11、16、21、25、31、35、41、45 层有岩浆格，可以走，每步掉 5% 当前生命，但能抄近路绕开门和怪。
- 商店 5/15/25/35/45，精英 9/19/29/39/49，清场门 14/34，祭坛 17/37。
- 支线入口提前到 8/18/28/38 层。
- 首领：矿洞守卫长、熔岩将军、地心骑士、深渊领主、地狱之王。

### 4. 陆地 · 目标：王冠

- **规则**：怪物掉落金币 ×2，商店价格 ×1.5——金币充裕，适合多买钥匙和高级商品。
- **驿站**：商店层（6/16/26/36/46）设有驿站，付 30×楼层 金币可坐马车去任何到过的驿站。
- 精英 8/18/28/38/48，清场门 12/32，机关 9/29/49，祭坛 21/41，诅咒宝箱较多（7/17/27/37/47）。
- 只有三条支线，25 层的试炼之间比其他界更早开放。
- 首领：边境守将、血色将军、亡灵骑士、暴君领主、篡位魔王。

### 5. 水中 · 目标：海神珠

- **规则**：药水效果减半，装备掉落翻倍。**最难的一界**，别省圣水，多靠吸血和闪避。
- **漩涡**：第 7、14、21、28、35、42、49 层各有一对漩涡，把你从一座卷到另一座。
- 商店 5/15/25/35/45，精英提前到 6/16/26/36/46，清场门 13/33。
- 首领：暗礁守卫、漩涡将军、沉船骑士、深渊领主、海渊魔王。

## 七、攻略建议

**参考曲线**（魔塔普通难度、正常清图、合理购物；其他界数值 ×5ᵏ，形状相同）

| 到达楼层 | 攻击 | 防御 | 生命 |
|---|---|---|---|
| 11 | ~70 | ~70 | ~5500 |
| 21 | ~200 | ~200 | ~6000 |
| 31 | ~430 | ~425 | ~8000 |
| 41 | ~770 | ~760 | ~9500 |
| 51 | ~1140 | ~1140 | ~20000 |

如果你明显低于这条线，说明漏了宝石或商店买得少；生命低于这条线，多半是硬打了还很疼的新怪。

1. **新怪先绕开**。每种怪会出现约 6 层：刚出现时很疼，拿几颗宝石后就几乎免费。先清老怪、拿宝石，最后再打新怪。
2. **防御追平怪物攻击是最划算的**。手册里伤害为 0 的怪随便打，金币经验白拿。
3. **商店攻防交替买**，攻击不够打不动精英时优先攻击。困难以上别买商店生命（除了真的快死）。
4. **精英是检查点**。打不过就回头逛店、找裂纹墙、走支线，而不是硬拼。
5. **钥匙留着开有回报的门**。黄门后通常是宝石或药水；蓝红门后往往是装备或捷径。
6. **隐藏支线值得走**。宝库和黄金宝匣能拿到高一档颜色的装备；勤快玩家到魔王殿时生命能多出 2~3 倍。
7. **饰品要强化**。帽子（暴击）对 Boss 很有效，戒指（吸血）在仙界和水中是续航核心，鞋（闪避）按期望减伤。
8. **圣水留到血多时喝**，祭坛在血少时献祭。
9. **在高界卡关**时可以回低界：那里的身体还在，能补齐精华、装备和金币（金币跨界会被限制，精华不会）。
